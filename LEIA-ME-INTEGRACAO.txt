PIXELS RIFA — INTEGRAÇÃO ONLINE APP ↔ CENTRAL

Esta versão corrige a limitação do localStorage.
Agora:
1. Ao salvar uma nova rifa no APP, ela é enviada para /api/rifa.
2. A Central de Rifas lê /api/rifa e mostra a rifa em andamento.
3. Ao encerrar, o resultado é arquivado online e a rifa atual é removida.
4. Funciona entre celular, computador, www e domínio sem www, desde que todos acessem o mesmo projeto Cloudflare.

CONFIGURAÇÃO ÚNICA NO CLOUDFLARE

A) Crie um banco D1
- Cloudflare Dashboard > D1 SQL Database > Create database
- Nome sugerido: pixels-rifas

B) Ligue o D1 ao seu projeto Pages
- Workers & Pages > seu projeto > Settings > Bindings
- Add binding > D1 database
- Variable name: PIXELS_DB
- Selecione o banco pixels-rifas
- Salve

C) Adicione a senha da administração
- Workers & Pages > seu projeto > Settings > Variables and Secrets
- Add
- Nome: PIXELS_ADMIN_PASSWORD
- Valor: 1807
- Pode usar Secret
- Salve

D) Faça novo deploy
Envie para o GitHub TODOS os arquivos deste pacote, inclusive:
functions/api/rifa.js

IMPORTANTE
- Não precisa criar tabela manualmente. A Function cria a tabela automaticamente no primeiro acesso.
- A página continua sendo HTML/CSS/JS. A única parte dinâmica é a pequena Function que grava/lê o D1.
- Se a integração online estiver indisponível, o APP continua mantendo os dados locais e tenta sincronizar novamente.
- No APP existe o botão “Sincronizar Central” para forçar a publicação da rifa atual.

TESTE
1. Abra app-rifa.html.
2. Entre como administrador.
3. Cadastre a rifa (nome, descrição, quantidade, valor e cartaz).
4. Clique “Salvar informações”.
5. Clique “Sincronizar Central”.
6. Abra central-rifas.html e atualize.
7. A nova rifa deve aparecer como “Em andamento”.
